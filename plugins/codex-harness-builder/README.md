# Codex Harness Builder Plugin

Skills-only Codex plugin for creating, updating, auditing, and compacting a token-efficient project development harness.

Primary invocation examples:

- `하네스 구성해줘`
- `하네스 업데이트해줘`
- `하네스 점검해줘`
- `하네스 경량화해줘`

This package has no MCP server, no authentication dependency, and no telemetry.
